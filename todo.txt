1. ✅ Select range: In the "Add faces to a name" tab, after selecting a name, it should be possible to select a range of the "Most similar unnamed faces". Maybe by holding SHIFT and selecting the first and the last image.

2. ✅ Export feature: In the "Add faces to a name" tab, after selecting a name, it should be possible to export all images of the selected person. The user should be able to select an output folder. Then all images (later also videos) that contain that person should be copied to the output folder. If an image isn't available, then the thumbnail should be copied to the output folder instead.

3. Implement video import: The app should also support tagging facces in videos. For that we will use ffmpeg4j to extract frames from the video. We will not extract all frames. Instead we limit frame extraction in the following way: not more than one frame per second; not more than 120 frames per video; the extracted frames should have the same "distance" to each other regarding time. We will then run face detection on those frames. Thumbnails of the frames and faces will be stored in the database, but referencing the video file as the source. The extracted frames can be deleted after that. See how ffmpeg4j works with the platform dependent GitHub actions.
