一款跨平台的**桌面应用**，按人物将您的照片集进行分类。它能在您的照片中检测
人脸，自动将相似的人脸分组，并允许您为每个人命名——然后可以查看、合并和整理
您的图库。一切都在您自己的电脑上本地运行：**您的照片绝不会离开您的设备。**

## 功能特性

- **导入照片时自动人脸检测**——每个检测到的人脸都会以缩略图形式保存，随时
  可以命名。
- **自动分组未命名的人脸**——相似的人脸会被聚集成簇，您可以一次性为同一个
  人的所有照片命名。
- **三种简单的命名方式：**
  - **为人脸命名**——按组处理未命名的人脸，从最大的组开始。
  - **为随机人脸命名**——浏览随机未命名的人脸，并为您选中的那些人命名。
  - **向某个名字添加人脸**——选择一个人，并为与TA最相似的未命名人脸命名。
- **重复检测**——比较您已命名的人，并允许您合并实际上属于同一人的名字。
- **浏览与检查**——一目了然地查看每个人，深入查看包含TA的照片，在系统查看器
  中打开原始图片，并移除人脸标签。
- **智能导入**——递归扫描子文件夹，并跳过已导入的照片（按内容而非文件名
  判断），因此重新导入同一文件夹不会有任何变化，同一张照片绝不会被存储两次。
- **路径筛选**——将命名限制在特定的文件夹或文件名范围内。
- **重命名与移除标签**——一次性修正所有地方的拼写错误，或从某个名字下移除
  人脸。
- **导出某个人的照片**——在*向某个名字添加人脸*中，选择任何一个人，即可将包含
  该人的所有照片复制到您选择的文件夹中（原始文件已丢失的照片会改为导出缩略图）。
- **首次运行模型下载**——内置的人脸识别模型只需下载一次（带进度窗口），并
  在本地缓存。
- **自动更新检查**——在有新版本发布时通知您。
- **反馈标签页**——直接在应用内发送错误报告和功能建议。
- **之后完全离线**——所有检测和匹配都在您的 CPU 上本地运行。

## 系统要求

- **Java 17 或更高版本**（需要 JDK，而不仅仅是 JRE）
- **64 位**桌面操作系统——Windows、Linux（x86_64 / aarch64）或 macOS
  （Intel / Apple Silicon）
- 大型照片集建议配备数 GB 可用内存
- **FFmpeg**——已随应用内置（通过 ffmpeg4j）；无需另行安装

## 下载

请从
[**Releases（发布页）**](https://github.com/psilo-hub/facesort/releases) 获取
最新版本——选择适合您平台的 jar 文件（`facesort-<platform>.jar`）。每个版本
都附带适用于所有平台的预编译 jar。无需编译或配置。

### 首次启动

1. 确保已安装 **Java 17+**（`java -version` 可查看版本）。
2. 运行 jar 文件：`java -jar facesort-<platform>.jar`（或双击运行）。
3. 首次启动时，Face Sort 会下载其人脸识别模型并显示进度窗口。这只需要
   一次网络连接。

之后一切都可以离线运行。

## 使用方法

主窗口由多个标签页组成。大致按以下顺序使用：

1. **导入图片**——点击*浏览…*选择照片文件夹（支持 JPG、JPEG、PNG、BMP、
   GIF、WebP；子文件夹会被递归扫描），然后点击**导入**。每个检测到的人脸都会
   连同其嵌入向量和缩略图一起保存。您可以随时停止导入；已导入的文件会保留。
   之后重新导入同一文件夹只会记录新文件。

2. **为人脸命名**——应用会聚类所有未命名的人脸，并显示最大聚类的代表。输入
   一个名字（输入时会自动识别已有的名字），点击**命名**；随后该聚类中剩余的
   相似人脸会被列出，您可以在同一轮中为它们命名。点击*下一个聚类*转到下一组。

3. **为随机人脸命名**——随机抽取一批未命名的人脸。点击人脸进行选择，输入
   名字，然后点击**为所选命名**。使用*路径前缀*字段可将样本限制在特定的文件夹
   或文件中。

4. **向某个名字添加人脸**——在左侧选择一个人；应用会按与该人平均嵌入向量的
   相似度对所有未命名的人脸排序，并显示最佳候选。选择多个后点击**为所选命名**——
   可逐个点击人脸，或按住 **Shift** 并点击第一张和最后一张人脸，即可选中两者之间
   的整个范围。勾选*"排除更接近其他名字的人脸"*复选框，则只显示最佳匹配为该选定人员
   的人脸；使用*路径前缀*字段可按文件夹筛选。您也可以在此**重命名…**任何人，或点击
   **导出图片…**，将所选人员的所有照片复制到您选择的文件夹中（缺失的原图会以缩略图
   形式导出）。

5. **去重**——点击**开始**按相似度比较名字对。对每一对决定：*这是重复项*
   （然后选择保留哪个名字——所有人脸都会被合并）、*这不是重复项*（会被永久
   记录），或*跳过*。

6. **查看**——浏览您已命名的收藏。每个人是一张卡片，显示代表性人脸和已命名
   人脸的数量。点击卡片可查看包含该人的图片；点击图片可打开原始文件，或使用
   右键菜单将该图片从这个人名下*移除标签*。

7. **设置**——调整人脸检测、聚类、导入和模型参数；各控件悬停提示中有详细
   说明。更改通过**保存**应用，或通过**恢复默认设置**重置。

8. **反馈**——向开发者发送错误报告或功能建议。

在整个应用中，您可以右键点击任何人脸或缩略图，在系统默认图片查看器中
**打开原始图片**；将鼠标悬停在某个人脸上会显示其源图片的路径。

### 推荐的工作流程

```
导入文件夹  →  为人脸命名 / 为随机人脸命名 / 向某个名字添加人脸（为人物命名）
           →  去重（合并重复的人物名字）
           →  查看（检查、打开原始文件、移除误标）
```

## 您的数据存储在哪里

所有数据都存放在应用旁边的 `config/` 文件夹中（首次启动时创建）——复制该
文件夹即可备份您的图库：

| 路径 | 用途 |
|------|------|
| `config/facesort.db` | 您的图库：照片、人脸、名字、标签 |
| `config/facesort-config.json` | 您的设置 |
| `config/CHANGELOG.md` | 自动更新检查使用的缓存 |
| FaceAI 模型缓存 | 已下载的模型——默认 `~/.djl.ai/cache`（Linux/macOS）或 `%USERPROFILE%\.djl.ai\cache`（Windows）；可通过*FaceAI 缓存目录*设置修改 |

所有设置都可以在**设置**标签页中更改（每个控件都有说明提示）；它们保存在
`config/facesort-config.json` 中。您也可以在那里切换界面的**语言**。
