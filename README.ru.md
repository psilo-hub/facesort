Кроссплатформенное **настольное приложение**, которое сортирует вашу коллекцию
фотографий по людям. Оно распознаёт лица на ваших фото, автоматически
группирует похожие и позволяет подписать каждого человека именем — затем можно
просматривать, объединять и наводить порядок в библиотеке. Всё выполняется
локально на вашем компьютере: **ваши фотографии никогда не покидают ваше
устройство.**

## Возможности

- **Автоматическое распознавание лиц** при импорте фотографий — каждое
  распознанное лицо сохраняется в виде маленькой миниатюры и готово к
  подписи.
- **Автоматическая группировка неподписанных лиц** — похожие лица объединяются
  в кластеры, чтобы можно было подписать все фотографии одного человека за
  один проход.
- **Четыре простых способа подписать лица:**
  - **Подписать лицо** — работайте с группами неподписанных лиц, начиная с
    самых больших.
  - **Подписать случайное лицо** — просматривайте случайные неподписанные лица
    и подписывайте выбранные.
  - **Добавить лица к имени** — выберите человека и подпишите неподписанные
    лица, наиболее похожие на него.
  - **Самые похожие** — показывает неподписанное лицо, наиболее похожее на одно
    из ваших имён, пара за парой.
- **Поиск дубликатов** — сравнивает ваших подписанных людей и позволяет
  объединять имена, которые оказались одним и тем же человеком.
- **Просмотр и проверка** — видите каждого человека с первого взгляда,
  переходите к фотографиям, открывайте оригиналы в системном просмотрщике и
  удаляйте подписи.
- **Умный импорт** — рекурсивно сканирует вложенные папки и пропускает уже
  импортированные фото (по содержимому, а не по имени файла). Повторный импорт
  той же папки ничего не меняет, и одно и то же фото никогда не сохраняется
  дважды.
- **Фильтр пути** — ограничьте подпись конкретной папкой или именем файла.
  Лица из видео сопоставляются по пути их видеофайла. Во вкладках *«Подписать
  случайное лицо»* и *«Добавить лица к имени»* щёлкните правой кнопкой по лицу и
  выберите **«Вставить путь в фильтр путей»**, чтобы заполнить поле источником
  этого лица: папкой изображения или полным путём (включая имя файла) видео, из
  которого взят кадр.
- **Удаление по префиксу пути** — во вкладке *«Импорт»* удалите все
  импортированные фото и видео, сохранённый путь которых начинается с
  введённого префикса. Диалог сначала покажет, сколько изображений, видео,
  миниатюр и лиц будет удалено; ничего не удаляется до подтверждения. Видео
  удаляются вместе с кадрами, извлечёнными из них.
- **Переименование и удаление подписи** — исправьте опечатку сразу везде или
  уберите лицо из имени.
- **Экспорт фотографий человека** — во вкладке *«Добавить лица к имени»*
  выберите любого человека и скопируйте все его фотографии в папку по вашему
  выбору (фотографии, чей оригинальный файл пропал, экспортируются как
  миниатюры).
- **Загрузка моделей при первом запуске** — встроенные модели распознавания лиц
  скачиваются один раз (с окном прогресса) и кэшируются локально.
- **Автоматическая проверка обновлений** — сообщает, когда выходит новая
  версия, и показывает примечания к выпуску.
- **Вкладка «Отзыв»** — отправляйте сообщения об ошибках и предложения функций
  прямо из приложения.
- **Затем полностью офлайн** — распознавание и сравнение работают локально на
  вашем процессоре.

## Требования

- **Java 17 или новее** (JDK, а не только JRE)
- **64-разрядная** настольная ОС — Windows, Linux (x86_64 / aarch64) или macOS
  (Intel / Apple Silicon)
- Для больших коллекций фото рекомендуется несколько ГБ свободной оперативной
  памяти
- **FFmpeg** — встроен в приложение (через ffmpeg4j); устанавливать ничего не нужно

## Скачивание

Скачайте последнюю сборку со страницы
[**Releases**](https://github.com/psilo-hub/facesort/releases) — выберите jar
для вашей платформы (`facesort-<platform>.jar`). Готовые jar-файлы для всех
платформ прикреплены к каждому релизу. Компиляция и настройка не требуются.

### Первый запуск

1. Убедитесь, что установлен **Java 17+** (`java -version`).
2. Запустите jar: `java -jar facesort-<platform>.jar` (или двойным щелчком).
3. При самом первом запуске Face Sort скачает модели распознавания лиц и
   покажет окно прогресса. Один раз потребуется подключение к интернету.

После этого всё работает офлайн.

## Как пользоваться

Главное окно — это набор вкладок. Проходите их примерно в таком порядке:

1. **Импорт изображений** — нажмите *Обзор…*, выберите папку с фотографиями
   (JPG, JPEG, PNG, BMP, GIF, WebP, ICO; вложенные папки сканируются рекурсивно),
   затем нажмите **Импорт**. Каждое распознанное лицо сохраняется вместе со
   своим эмбеддингом и миниатюрой; обрезок сохраняется в вертикальном
   положении: лицо, сфотографированное сбоку или вверх ногами, сначала
   поворачивается на ближайшую четверть оборота. Библиотеки, импортированные
   более старой версией, после этого обновления выравниваются один раз
   автоматически, в фоновом режиме, при первом запуске. Импорт можно
   остановить в любой момент;
   уже импортированные файлы сохраняются. Повторный импорт той же папки
   фиксирует только новые файлы.
   Чтобы удалить записи, сохранённый путь которых начинается с заданного
   префикса (например, после удаления исходных файлов папки), нажмите
   **Удалить по префиксу пути…** — диалог сначала покажет, сколько
   изображений, видео, миниатюр и лиц будет удалено, и запросит подтверждение.

2. **Подписать лицо** — приложение группирует все неподписанные лица и
   показывает представителя самого большого кластера. Введите имя (существующие
   имена распознаются по мере ввода) и нажмите **Подписать**; затем будут
   предложены остальные похожие лица кластера, чтобы подписать их за один
   проход. Переходите к следующему кластеру кнопкой *Следующий кластер*.

3. **Подписать случайное лицо** — случайная выборка неподписанных лиц.
   Щёлкайте по лицам, чтобы выбрать их, или, удерживая **Shift**, щёлкните по
   первому и последнему лицу, чтобы выбрать весь диапазон между ними; затем
   введите имя и нажмите **Подписать
   выбранные**. Поле *префикс пути* ограничивает выборку конкретной папкой или
   файлом (кадры видео сопоставляются по пути их видеофайла). Щёлкните правой
   кнопкой по лицу и выберите *«Вставить путь в фильтр путей»*, чтобы заполнить
   поле папкой этого лица или — для кадра видео — полным путём его исходного
   видео. Щёлкните правой кнопкой по лицу и выберите *«Не лицо»*, чтобы отклонить
   обнаружение, которое на самом деле не является лицом: с этого момента оно
   исключается из всех списков неподписанных лиц, но сохранённое изображение
   остаётся.

4. **Добавить лица к имени** — выберите человека слева; приложение ранжирует
   каждое неподписанное лицо по сходству со средним эмбеддингом этого человека
   и показывает лучших кандидатов. Выберите несколько и нажмите **Подписать
   выбранные** — щёлкайте по лицам по одному или, удерживая **Shift**, щёлкните
   по первому и последнему лицу, чтобы выбрать весь диапазон между ними. Флажок
   *«Исключить лица, которые ближе к другому имени»* оставляет только лица, чьё
   лучшее совпадение — выбранный человек, а поле *префикс пути* фильтрует по
   папке (щёлкните правой кнопкой по лицу и выберите *«Вставить путь в фильтр
   путей»*, чтобы заполнить поле папкой этого лица или — для кадра видео —
   полным путём его исходного видео). Здесь же можно **Переименовать…** любого
   человека или нажать
   **Экспортировать изображения…**, чтобы скопировать все фотографии
   выбранного человека в папку по вашему выбору (отсутствующие оригиналы
   экспортируются как миниатюры). Щёлкните правой кнопкой по неподписанному
   лицу-кандидату и выберите *«Пометить другим именем»*, чтобы подписать его
   именем, отличным от предложенного: диалог показывает предпросмотр
   существующих имён с их наиболее представительным лицом и сходство со
   средним эмбеддингом имени. Щёлкните правой кнопкой по неподписанному
   лицу-кандидату и выберите *«Не лицо»*, чтобы отклонить обнаружение, которое на
   самом деле не является лицом, — тогда оно перестанет предлагаться любому имени.

5. **Самые похожие** — приложение показывает неподписанное лицо, наиболее
   похожее на одно из ваших имён, рядом с лицом, уже подписанным этим именем,
   вместе с обоими значениями схожести. Выберите *Одна и та же персона*
   (неподписанное лицо получает это имя), *Не та же персона* (сочетание
   запоминается и больше не предлагается ни на одной вкладке) или *Пропустить*
   (пара откладывается на эту сессию и вернётся при следующем запуске).
   Следующая пара появляется сразу после каждого выбора.

6. **Удаление дубликатов** — нажмите **Начать**, чтобы сравнивать пары имён по
   сходству. Для каждой пары решите: *Это дубликаты* (затем выберите, какое имя
   сохранится — все лица будут объединены), *Это не дубликаты* (запомнится
   навсегда) или *Пропустить*.

7. **Просмотр** — просматривайте подписанную коллекцию. Каждый человек — это
   карточка с представительным лицом и количеством подписанных лиц. Поле поиска
   фильтрует карточки по имени по мере ввода, так что список остаётся удобным
   даже при сотнях людей. Щёлкните по
   карточке, чтобы увидеть изображения с этим человеком; щёлкните по
   изображению, чтобы открыть оригинал, или воспользуйтесь контекстным меню,
   чтобы *снять подпись* с этого человека.

8. **Настройки** — настройте распознавание лиц, кластеризацию, импорт и
   параметры моделей; подробности в подсказках элементов управления. Изменения
   применяются кнопкой **Сохранить** или сбрасываются кнопкой **Сбросить к
   настройкам по умолчанию**.

9. **Отзыв** — отправьте разработчикам сообщение об ошибке или предложение
   функции.

В любом месте приложения можно щёлкнуть правой кнопкой по лицу или миниатюре,
чтобы **Открыть оригинал** в системном просмотрщике изображений по умолчанию,
а наведение на лицо показывает путь к его исходному изображению.

### Рекомендуемый порядок работы

```
Импорт папки  →  Подписать лицо / Подписать случайное лицо / Добавить лица к имени / Самые похожие (подписать людей)
             →  Удаление дубликатов (объединить повторяющиеся имена)
             →  Просмотр (проверить, открыть оригиналы, снять ошибочные подписи)
```

## Где хранятся ваши данные

Всё находится в папке `config/` рядом с приложением (создаётся при первом
запуске) — скопируйте её, чтобы сделать резервную копию библиотеки:

| Путь | Назначение |
|------|------------|
| `config/facesort.db` | Ваша библиотека: фото, лица, имена, подписи |
| `config/facesort-config.json` | Ваши настройки |
| `config/latest-release.json` | Кэш для автоматической проверки обновлений |
| Кэш моделей FaceAI | Скачанные модели — по умолчанию `~/.djl.ai/cache` (Linux/macOS) или `%USERPROFILE%\.djl.ai\cache` (Windows); настраивается параметром *FaceAI cache dir* |

Все настройки можно изменить на вкладке **Настройки** (у каждого элемента есть
поясняющая подсказка); они сохраняются в `config/facesort-config.json`. Там же
можно сменить **язык** интерфейса; окно при этом перестраивается, поэтому
выполняющийся импорт останавливается (уже импортированные элементы
сохраняются). Этот файл можно править и вручную:
неизвестные настройки игнорируются, а значения вне допустимых пределов
приводятся к допустимым, поэтому файл из другой версии всё равно запустит
приложение. Настройки записываются атомарно, поэтому прерванное сохранение
никогда не повредит файл.

Помимо параметров обнаружения и кластеризации можно также настраивать бюджеты
импорта: качество JPEG сохраняемых миниатюр и обрезков лиц, максимальное число
кадров, извлекаемых из видео, и размер обрезки лица — так импорт можно
сбалансировать между качеством и скоростью.
